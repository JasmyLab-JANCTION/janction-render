# JANCTION Render for VS Code

Adds the [JANCTION Render](https://render.janction.jp) MCP server to VS Code, so GitHub Copilot's agent mode (and any MCP-aware chat in VS Code) can render Blender scenes and 3D models on cloud GPUs.

- Preview a `.blend`, a bpy script or a GLB / FBX / USD / OBJ file in seconds, with a check that says what looks wrong and how to fix it
- Final frames or an MP4, product shots, 360-degree turntables
- No local GPU or Blender. The first connection opens a consent page in the browser; no sign-up form

## Use

1. Install this extension.
2. Open the Chat view in agent mode and ask, for example: "Render a preview of scene.blend on JANCTION Render".
3. Approve the connection when the browser opens.

The price of a render is shown before it runs, and paid renders need your approval. Details: https://render.janction.jp/pricing
